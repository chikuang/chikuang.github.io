# Chi-Kuang Yeh 葉啓光 — Personal Academic Website

This is the personal academic website of **Chi-Kuang Yeh (葉啓光)**,
Assistant Professor in Statistics at **Georgia State University**.

- **Website:** [chikuang.github.io](https://chikuang.github.io/)
- **Website source:** [chikuang/website](https://github.com/chikuang/website)

[website repository](https://github.com/chikuang/website).
