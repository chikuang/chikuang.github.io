Learn and teach with Python

The publishing approach

This course uses Quarto book + Python/Jupyter. It retains the chapter navigation, search, mathematical notation, code blocks, and cross-references of the existing statistics courses while executing Python examples. Quarto supports both text-based .qmd files and Jupyter .ipynb notebooks. See the official Python guide and book guide.

Approach Authoring style Fit for this course
Quarto + Python/Jupyter Markdown, equations, and executable Python in .qmd; notebooks also supported Selected: retains the existing course structure and a single prose/code source
Jupyter Book MyST Markdown and notebooks organized as a book A suitable alternative for a notebook-centered collection; it would require a different site configuration

The current Jupyter Book documentation describes Jupyter Book 2, based on the MyST document engine. Instructions for Jupyter Book 1 use a different configuration; avoid mixing the two.

One source, two ways to learn

Use .qmd as the canonical source for this course. Render it as a web chapter and export the first lab as a notebook for experimentation. Changes to the exported notebook are personal practice until incorporated back into the .qmd source.

Text + equations + Python (.qmd)
              |
       Jupyter executes code
              |
       Quarto renders the book
              |
      Course website (_book/)

The same lab .qmd → downloadable .ipynb → interactive practice

Set up the course

Install Python and Quarto first. Python 3.12 is used for the initial verified build. In a terminal:

git clone https://github.com/chikuang/Teaching-GenAI.git
cd Teaching-GenAI
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
quarto check jupyter
quarto preview

On Windows, create the environment with py -m venv .venv and activate it in PowerShell with .venv\Scripts\Activate.ps1. The remaining python and quarto commands are the same. Quarto is a separate application, so it must also be available on the terminal’s PATH.

If Quarto selects a different Python installation, set QUARTO_PYTHON to the full path of this environment’s Python executable. On macOS/Linux after activation:

export QUARTO_PYTHON="$PWD/.venv/bin/python"

Start with NumPy and Matplotlib. PyTorch and model libraries are introduced in later modules, following their current official installation instructions; they are not needed for the first lab.

Write a chapter

Create a file such as 02-attention.qmd. Add it to book.chapters in _quarto.yml. A minimal chapter looks like this:

---
jupyter: python3
---

# A small probability model

We begin with a categorical distribution.

```{python}
import numpy as np
p = np.array([0.6, 0.3, 0.1])
print(p.sum())
```

quarto preview rebuilds the page as you edit. quarto render builds the complete website in _book/. Executable examples are run during the build, and a Python error fails the build. The HTML contains their saved outputs.

Use a notebook in class

quarto convert 01-python-lab.qmd --output notebooks/01-python-lab.ipynb
jupyter lab notebooks/01-python-lab.ipynb

In JupyterLab, run the notebook from top to bottom, change a parameter, and compare the result. To author a later chapter directly as .ipynb, list that notebook in book.chapters and use quarto render --execute to recompute its outputs. By default, Quarto normally uses the outputs already stored in an .ipynb; see the execution guide.

A repeatable lesson structure

  1. Start with one statistical question and a small data-generating example.
  2. Write the model, objective, and assumptions before using a high-level library.
  3. Implement the smallest useful calculation; show shapes, outputs, and diagnostic plots.
  4. Change one assumption or parameter and predict what should happen.
  5. End with an explanation, a limitation, and one exercise that tests understanding.

Reproducibility and publication

Use the version ranges in requirements.txt for a fresh environment. requirements-lock.txt records the exact package versions from the initial macOS/Python 3.12 build; it is a record of that environment and may need platform-specific adjustments elsewhere. Record seeds, data provenance, and model versions when adding future experiments.

The source lives in Teaching-GenAI on GitHub. The rendered book is published under teaching/genai/ in the existing personal website repository. The repository README documents the render and publication steps.
