Question 1: Cross-Validation [6]

Select one best answer per item (1 point each). Unless stated otherwise, observations are independent. The prediction target is a new observation from the same population.

(a) What is tuned? [1]

A polynomial regression uses least squares. CV compares degrees 1, 2, and 3. Which quantity is the hyperparameter being tuned?

A. The fitted intercept.
B. The estimated residual variance.
C. The polynomial degree.
D. The number of held-out predictions stored in a vector.

(b) Feature selection [1]

A procedure selects predictors using their associations with the outcome. It then fits a regression. How should CV evaluate this whole procedure?

A. Select predictors using all development outcomes. Then cross-validate only the regression fit.
B. Select predictors within each training set. Fit the model there and predict the held-out fold.
C. Select predictors using the final test outcomes.
D. Select predictors using each validation fold’s outcomes.

(c) Predicting new people [1]

Each patient has four visits. We want to predict outcomes for new patients. How should the folds be formed?

A. Randomly assign visits to folds. One patient’s visits may appear in different folds.
B. Use each patient’s first visit for validation and their other visits for training.
C. Use patient ID as a predictor. Then split visits randomly.
D. Assign patients to folds. Keep each patient’s visits together.

(d) Predicting the future [1]

We want to forecast next month’s demand using past monthly records. Which validation design fits this goal?

A. Shuffle months into random folds. Allow later months to predict earlier ones.
B. Train on earlier months and validate on later months.
C. Train on later months and validate on earlier months.
D. Fit to every month and report the training error.

(e) Leave-one-out CV [1]

Use a fixed dataset and a deterministic fitting procedure. Which statement about LOOCV is correct?

A. It uses one fitted model to predict all observations.
B. Its prediction error must be zero because each training set is large.
C. It needs no random fold assignment. Collecting a new dataset can change its score.
D. It is guaranteed to have lower variability than 5-fold CV.

(f) Reusing the test set [1]

An analyst checks the final test error. They then change the polynomial degree to get the lowest error on that same test set. What has happened?

A. The test set now guides model selection. It no longer provides an untouched final assessment.
B. The test set is still untouched because it was not used to fit coefficients.
C. CV automatically adjusts for this extra model selection.
D. A final refit on the development data removes any bias in the selected test score.

Question 2: Jackknife and Bootstrap [6]

Select one best answer per item (1 point each). Use the ordinary delete-one jackknife and the nonparametric bootstrap. Assume independent observational units.

(a) Resampling paired measurements [1]

Each of 20 patients has a baseline and a follow-up measurement. We want to bootstrap their correlation. How should one bootstrap sample be formed?

A. Independently resample the baseline and follow-up columns.
B. Randomly reorder all 20 patient rows without replacement.
C. Sample 20 patient IDs with replacement. Keep both measurements from each selected patient.
D. Draw 20 baseline measurements and keep the follow-up column in its original order.

(b) What does the histogram describe? [1]

Compute one correlation from each of 5,000 bootstrap samples. What does a histogram of these correlations describe?

A. Variation of the statistic when resampling the observed data. This approximates its sampling distribution.
B. The population distribution of individual patient measurements.
C. The distribution of 5,000 newly recruited patients.
D. The exact sampling distribution under the unknown population, without approximation.

(c) The sign of estimated bias [1]

The observed estimate is \(\hat\theta=0.60\), and the bootstrap estimates average 0.57. What are the bootstrap bias estimate and the corresponding bias-corrected estimate?

A. Bias \(=0.03\); corrected estimate \(=0.57\).
B. Bias \(=-0.03\); corrected estimate \(=0.63\).
C. Bias \(=-0.03\); corrected estimate \(=0.57\).
D. Bias \(=0.57\); corrected estimate \(=0.03\).

(d) Interpreting a confidence procedure [1]

Consider a nominal 95% bootstrap confidence procedure for a population correlation. Assume its approximation is appropriate. What is its frequentist interpretation?

A. About 95% of individual measurements fall inside each interval.
B. It is a 95% prediction interval for the next patient’s measurement.
C. Across repeated original samples, about 95% of the intervals contain the fixed population correlation.
D. For the one computed interval, the fixed parameter has probability 0.95 of lying inside it.

(e) More resamples [1]

For the same dataset, increase \(B\) from 2,000 to 8,000. The bootstrap draws are independent. Which statement is correct?

A. The conditional Monte Carlo SE of the bootstrap mean is approximately halved. The original sample size stays the same.
B. The original estimator’s sampling SE must be halved.
C. The dataset now contains four times as many independent observations.
D. Selection bias in the original sample is removed.

(f) Jackknife versus LOOCV [1]

Both jackknife and LOOCV omit one observation at a time. What is the usual goal of each method?

A. Both estimate prediction error by averaging the retained-sample correlations.
B. Jackknife predicts the omitted outcome; LOOCV estimates bias from parameter replicates.
C. Jackknife requires random fold assignments, whereas LOOCV samples with replacement.
D. Jackknife uses parameter estimates to estimate SE and bias. LOOCV averages held-out losses to assess prediction.

Question 5: Checking a CV Implementation [4]

n <- nrow(dat)
fold_id <- rep(1:5, each = 4)
pred <- numeric(n)

fit <- lm(y ~ x, data = dat)
for (k in 1:5) {
  held_out <- fold_id == k
  pred[held_out] <- predict(fit, newdata = dat[held_out, ])
}

cv_mse <- mean(dat$y - pred)^2
